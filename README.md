🍱 SYSU-Food-Picker (康乐园美食审判台)
“今天吃什么？” —— 解决中山大学康乐园干饭人的终极难题。
本项目是一款基于 HarmonyOS ArkTS 开发的智能决策应用，通过多维权重算法与现实时空感知，拯救你的“干饭决策疲劳”。

✨ 核心亮点 (Features)
🎲 V1.0 基础框架：经典的命运转盘
[x] 分类均衡随机：四大分类（食堂、外卖、出去吃、泡面）平等抽取，告别选择困难。

[x] 加权推荐算法：引入评价体系，高评分店铺拥有更高出场率。

[x] 南校区定制数据：预设松涛园、南门潮汕牛肉等周边真实美食数据，即开即用。

🧠 V2.0 智能引擎：让算法拥有“常识”
[x] 天气联动惩罚：开启下雨模式，自动大幅降低“出去吃”的概率，拉满“外卖/泡面”权重。

[x] 时空动态修正：系统自动读取当前时间，在 18:00 等就餐高峰期自动拉长人气店铺的预估等候时长。

[x] 渐进式财务拦截：引入预算滑块（Slider），算法将在摇号前无情封杀所有超出你当前预算的“钱包刺客”。

[x] 工业级数据录入：支持通过多行文本批量导入饭单，正则匹配一键解析。

🛰️ V3.0 现实链接：全自动时空与 LBS 感知 (Current)
[x] 精准 LBS 物理测距：全面接入 LocationKit 与 Haversine 算法，实时计算并展示你与餐厅的精准物理距离（如 📍 300m）。

[x] Smart Scatter 智能打散防重叠：独创防坐标重叠算法，为没有经纬度的店铺智能分配符合其类型（食堂/外卖）的拟真坐标。

[x] 并行时间流计算：将总耗时严谨拆分为「🚶步行」与「⏳等候」。首创“外卖并行逻辑”（总耗时取步数与等候的最大值），真实还原干饭物理规律。

[x] API 自动气象感知：接入鸿蒙 NetworkKit 与真实天气 API，无感同步当前校园气象，自动触发算法演变。

🗺️ 未来演进方向 (Roadmap)
本项目目前已具备完整的单机应用形态，未来计划向更深度的“校园社群工具”与“元服务”方向演进：

🌐 从单机到社群 (Crowdsourcing)

云端公认饭单：接入云数据库，支持同学们订阅并共享“南校区神仙干饭列表”。

实时拥挤度战报：引入类似地图路况的众包机制，用户可一键上报“松涛园排队爆满”，系统自动同步调低所有用户的当期权重。

🎨 桌面端与无缝体验 (Atomic Service)

HarmonyOS 万能卡片：开发 2x2 或 4x2 的桌面 Service Widget，实现免打开 App，在桌面一键“摇号”。

OCR 菜单识别录入：接入视觉 API，拍一下传单即可自动生成带价格的店铺数据。

💕 情感化与社交交互 (Social)

双人/情侣同步模式：两人通过碰一摇一摇，系统自动计算双方饭单的“最大公约数”，解决两人聚餐的意见分歧。

饭后红黑榜机制：摇号完成后增加真实反馈打分，动态改变该店铺在你个人权重池中的长期地位。

🛠️ 技术栈与架构 (Tech Stack)
开发语言: ArkTS (HarmonyOS 声明式开发语言)

UI 框架: ArkUI (大量应用毛玻璃特效 BlurStyle 与弹簧动画 springMotion)

系统能力: NetworkKit (HTTP 通信), LocationKit (高精度定位服务)

持久化方案: PersistentStorage (确保应用重载后饭单数据不丢失)

👨‍💻 开发者感悟
